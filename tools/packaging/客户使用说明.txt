BigScreen 离线部署使用说明

一、推荐方式：使用安装包
1. 将 BigScreen-版本号-win-x64-setup.exe 复制到客户电脑，双击并允许管理员授权。
2. 分别选择程序安装目录、数据保存目录及服务端口。
   数据目录可选择 D:\BigScreenData 等本机文件夹，不支持网络共享目录。
3. 如需其他局域网电脑访问，勾选允许局域网访问，并将现场网络设置为可信的专用网络。
4. 安装完成后后台服务自动运行，电脑重启后自动启动；不需要保持命令行窗口。
5. 本机访问：http://127.0.0.1:所选端口/screen
   数据后台：http://127.0.0.1:所选端口/edit
   其他设备：http://服务电脑IP:所选端口/screen
6. 首次登录账号 admin，密码 admin123；交付使用前请在员工管理中修改密码。

二、数据、日志与升级
1. 数据库：所选数据目录\dashboard.sqlite3。
   日志：所选数据目录\logs；升级备份：所选数据目录\backups。
2. 同一电脑只安装一个“固联轻量化 生产监控”服务。升级时使用相同的程序目录及数据目录。
   安装程序停止旧服务，在新服务首次访问数据库前在线备份，再启动新版本。
3. 卸载仅移除程序、服务和本项目防火墙规则；保留数据、备份和日志。
4. 如需迁移数据目录，先在 Windows“服务”中停止“固联轻量化 生产监控”，完整复制原数据目录，
   卸载后重新安装并选择新目录；确认数据完整前保留原目录。
5. 恢复备份前必须停止服务，保留现有库及其 -wal、-shm 文件到其他目录，
   然后将备份复制为 dashboard.sqlite3；不要混用旧库的 WAL/SHM 文件。
6. 升级失败时请查看安装日志和服务日志。升级不提供自动回退；恢复旧版需同时核对备份。

三、便携包（无需注册服务）
1. 解压整个 portable.zip，保留全部文件。不要单独复制 BigScreen.exe。
2. 用记事本打开 BigScreen.ini，可修改 port 和 data_directory，保存为 UTF-8。
   数据目录可填写绝对路径，例如 D:\BigScreenData；默认 data 表示程序旁的 data 目录。
3. 双击“启动.cmd”，保持窗口运行；关闭窗口即停止服务。
4. 便携包不自动配置开机启动和防火墙。

四、运行环境与排查
1. 面向 Windows 10/11、Windows Server 2016+ 的 64 位系统，需 .NET Framework 4.6.1+。
   安装包包含 Python 和业务依赖，客户电脑不需要安装 Python 或联网下载依赖。
2. 打不开页面时：先检查 Windows“服务”中的“固联轻量化 生产监控”，再检查日志及端口占用。
   本机可访问但其他电脑不能访问时，检查网络类型、防火墙和服务电脑 IP。
3. 安装包未做商业代码签名；Windows 或杀毒软件可能提示未知发布者，请核对来源及 SHA256SUMS.txt。
