# BigScreen

智能制造生产监控大屏，使用原生 HTML、CSS、JavaScript 和 ECharts 5.4.3。

## 预览

直接打开 `bigScreen.html`，或在项目目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8765/bigScreen.html>。

## 显示适配

- 主要目标：**1440 × 720**，建议浏览器全屏、页面缩放 100%。
- 该尺寸下全部模块整屏展示，仅库存明细区域内部滚动。
- 更大桌面按可用空间伸展；平板采用两列，手机采用单列。
- 两张库存表默认以每秒 10 像素慢速滚动，首尾停留 2 秒；支持按钮暂停/继续、悬停暂停、键盘聚焦暂停及手动滚动。
- 原材料的物料、仓库、规格、部位、库存、重量、状态和可切分别独立成列；半成品的类别、物料、仓库、规格和库存分别独立成列。

## 数据与依赖

- 产线、库存、出货和安全天数均为静态示例数据，尚未接入业务接口。
- 零库存提示对应现有两条库存为零的物料；激光焊接工序显示现有 B 线维护状态。
- 图表通过 jsDelivr CDN 加载 ECharts，需要联网；加载失败时显示提示，时钟和库存交互仍可使用。
