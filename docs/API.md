# 接口与数据口径

页面与接口由同一个 Flask 服务提供。写入请求使用 `application/json`，成功返回新版本；错误返回 `{"error":"中文错误信息"}`。

除 `/api/health`、`/api/dashboard` 和 `/api/auth/login` 外，全部 API 均要求登录 Cookie，未登录或会话失效返回 HTTP 401；`/edit` 未登录跳转 `/login`。跨站来源的写入返回 403。员工会话有效期 12 小时；停用、删除或改密后旧会话失效。大屏及其读取接口公开。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/screen` | 联网大屏，主要目标 1440 × 720 |
| GET | `/edit` | Vue 3 + Element Plus 编辑页 |
| GET | `/login` | 员工登录页；已登录跳转编辑页 |
| POST | `/api/auth/login` | 提交 `username`、`password`，成功设置 HttpOnly、SameSite=Lax Cookie |
| GET | `/api/auth/session` | 当前员工信息，不含密码 |
| POST | `/api/auth/logout` | 清除当前浏览器登录会话 |
| GET | `/api/employees` | 读取 `employees`、`version`、`updated_at`，已有密码返回空串 |
| PUT | `/api/employees` | 按版本保存完整员工列表，移除的员工会被删除 |
| GET | `/api/health` | 服务及 SQLite 健康检查 |
| GET | `/api/dashboard` | 当前业务日全部计算结果；不缓存 |
| GET | `/api/editor?date=2026-11-21&month=2026-11` | 读取原始编辑数据及版本；省略日期时使用业务日 |
| PUT | `/api/production/<YYYY-MM-DD>` | 一次保存该日日报、全局指标、与该日相交的停机记录 |
| PUT | `/api/inventory` | 一次保存原材料和半成品完整列表 |
| PUT | `/api/sales/<YYYY-MM>` | 保存当月订单量及全部件号累计出货 |
| PUT | `/api/settings` | 保存业务时区、安全起算日期、产线配置、独立工序状态 |
| POST | `/api/downtime/start` | 按服务器时间立即开始一条产线的停机 |
| POST | `/api/downtime/<id>/finish` | 按服务器时间结束未结束的停机 |

## 版本与事务

每个写入请求必须携带读取时得到的 `version`。版本不一致返回 HTTP 409，保留服务端原数据，编辑页保留未保存草稿。

同一模块的一次保存使用 SQLite `BEGIN IMMEDIATE` 事务；任意校验或数据库约束失败都回滚，成功后统一递增版本。大屏读取同一数据库快照，避免读到跨表的半批数据。

## 员工账号

首次启动创建 `admin / admin123`，已有业务数据库也自动补建账号表，重启不重置密码。所有启用员工均可编辑数据及管理员工。账号为 1～40 位英文字母、数字、下划线、点或短横线，不区分大小写；姓名为 1～40 字；密码按要求明文保存，最长 128 字。员工列表不回传已有密码。

`PUT /api/employees` 示例：

```json
{"version": 0, "employees": [
  {"id": 1, "username": "admin", "name": "管理员", "password": "", "enabled": true},
  {"username": "worker01", "name": "张三", "password": "123456", "enabled": true}
]}
```

新员工不传 `id` 且必须设置密码；旧员工密码留空表示保留原密码。禁止删除或停用当前登录账号。停用、删除、修改密码均撤销目标员工旧会话，重新启用也不恢复旧会话；修改当前登录员工密码会保留此次会话。

## 业务表

数据库按字段保存，没有 `data_json` 数据列。

| 表 | 保存内容 |
|---|---|
| `production_line` | 固定产线编号、名称、标准日产量、关联工序、趋势显示范围 |
| `production_daily` | 日期、产线、实际产量、不良数量；日期与产线联合主键 |
| `line_downtime` | 产线、停机起止时间、原因、备注；结束时间可空表示未结束 |
| `raw_material_stock` | 物料、仓库、规格、部位、库存、单位、重量 kg、可切件数 |
| `semi_finished_stock` | 类别、物料、仓库、规格、库存、单位 |
| `sales_month` | 月份、订单件数 |
| `shipment_month_item` | 月份、件号、累计出货件数；月份与件号唯一 |
| `daily_overview` | 日期及全局计划、完成量、设备综合效率、品质合格率、平均产出 |
| `process_node` | 工序名称、现有切图路径、顺序，以及钢卷/出货两个独立工序状态 |
| `screen_settings` | 统一业务时区、安全起算日期、数据版本、最近保存时间 |
| `employee` | 员工账号、姓名、明文密码、启用状态及会话版本 |
| `auth_settings` | 持久化登录签名密钥，使重启后有效会话保持可用 |

## 日报请求

`GET /api/editor` 中的 `production` 可作为草稿基础，保存时再加上 `version`。`lines` 必须包含四条固定产线，每项提供 `id`、`actual_qty`、`defect_qty`；缺失数量用 `null` 表示。

`overview` 提供 `planned_qty`、`actual_qty`、`oee_percent`、`quality_percent`、`average_output`，均可空。设备综合效率、全局品质及平均产出第一版手填，产线不良率和综合达成率自动计算。

停机记录示例：

```json
{
  "line_id": 4,
  "start_at": "2026-11-21T11:00:00",
  "end_at": "2026-11-21T13:00:00",
  "kind": "maintenance",
  "note": "设备维护"
}
```

`kind` 支持 `stopped`、`maintenance`、`fault`。已有记录需带 `id`，从本日列表移除的已有记录会被删除。跨天记录可从相交的任一天编辑。重复覆盖的停机区间按时间并集合计，不重复扣减。

## 计算规则

- 运行率统计业务时区当天 00:00 至服务器当前时刻，只扣除已发生的停机部分。凌晨零分母显示“—”。
- 停机状态按 `[开始时间, 结束时间)` 判断；结束时自动恢复。未来时段尚未发生时不提前停机或扣减运行率。
- 未指定偏移的日期时间按配置的业务时区解释，数据库统一保存 UTC。接口也接受带偏移的 ISO 日期时间；夏令时不存在的时间会拒绝。
- 未录入数量保留 `null`，明确录入的 `0` 才代表零产量/零库存。
- 产线月累计来自当月已录入日报。趋势使用最近 30 个业务日及配置勾选的 1～4 条产线，默认选择 A/B 拼焊线；缺少任一所选产线数据时该日合计柱为空，已完整录入的日期参与“已录入累计”。
- 全局实际完成与各工序产量属于独立统计范围；综合达成率由全局完成量除以全局计划量。
- 原材料与半成品按单位分别汇总，不混加卷、张、件等单位。重量和可切件数为空时显示“—”。
- 月累计出货汇总全部件号，大屏降序取前八项；编辑页保留全部件号。
- 本月订单量的单位为件，出货达成率使用相同数量口径。
- 安全天数为业务日期与起算日期之差，起算当天为 0 天。
- 生产相关工序状态取关联产线的当前状态；单独 B 线维护时显示“B线维护”。钢卷、出货状态在设置页独立维护。

## 趋势产线配置

`PUT /api/settings` 的 `lines` 中可以提交 `show_in_trend`，支持布尔值或整数 0/1；四条产线中必须至少选中一条。未提交该字段的旧客户端会保留已有选择。保存失败时，名称、标准产量、选择和版本一起回滚。

产线名称可编辑，固定 ID 不变，不重新创建日报和停机记录。大屏曲线名称、图例、相关停机告警使用当前名称，颜色按固定 ID 分配。合计柱名为“所选产线合计”，累计值也只统计所选产线。
